## Ejercicio 1: Entidad de Dominio "User"

### Prompt Efectivo

```markdown
Cree una entidad de usuario para una API del portal de empleo siguiendo los principios de clean architecture.
La entidad debe tener:
- Id: Guid (clave principal, generada por la aplicación)
- Correo electrónico: cadena (única, máximo 256 caracteres, se requiere un formato de correo electrónico válido)
- Contraseña: cadena (se codificará con BCrypt, nunca se almacenará texto sin formato)
- Nombre: cadena (máximo 100 caracteres, obligatorio)
- Fecha de Nacimiento: FechaHora (debe tener al menos 16 años de antigüedad de validación en servicio)
- Teléfono: cadena (opcional, formato internacional)
- Habilidades: Lista<cadena> (opcional, habilidades del candidato)
- Rol: enumeración UserRole (CANDIDATO, EMPRESA, ADMIN, CANDIDATO predeterminado)
- IsActive: bool (verdadero por defecto, para funcionalidad de eliminación temporal)
- Creado en: Fecha y hora (configuración automática en la creación)
- Actualizado en: Fecha y hora (configuración automática al modificar)

Incluya documentación XML para todos los miembros públicos.
Devuelve solo el código C# para la clase de entidad.
```

## Ejercicio 2: Servicio de Autenticación

### Prompt Efectivo

```markdown
Create an AuthService class for a Job Portal API that implements authentication logic.

Dependencies:
- IUserRepository: for user data access
- IUnitOfWork: for transaction management
- IConfiguration: for JWT settings (secret key, issuer, audience)
- SignInManager<User>: for password validation

Methods to implement:
1. RegisterAsync(RegisterDto dto) -> AuthResultDto
   - Validates email doesn't exist in database
   - Hash password with BCrypt (work factor 12)
   - Creates user with CANDIDATE role by default
   - Returns AuthResultDto with JWT tokens

2. LoginAsync(LoginDto dto) -> AuthResultDto
   - Finds user by email
   - Validates password with SignInManager
   - Checks user IsActive flag
   - Generates JWT access token (60 min expiry) and refresh token (7 days expiry)
   - Returns AuthResultDto with tokens and user info
   - Throws InvalidCredentialsException if auth fails

3. RefreshTokenAsync(RefreshTokenDto dto) -> AuthResultDto
   - Validates refresh token is not expired and exists in database
   - Generates new access token with same refresh token
   - Updates refresh token expiry

JWT Configuration:
- Algorithm: HS256
- Claims: sub (userId), email, role, exp, jti
- Access Token: 60 minutes expiry
- Refresh Token: 7 days expiry

Custom Exceptions to throw:
- InvalidCredentialsException (wrong email/password)
- UserNotFoundException (email not found)
- UserInactiveException (IsActive = false)
- InvalidRefreshTokenException (expired or invalid)

Include XML documentation for all public methods.
Return only the C# code for the service class.
```

### Código Generado Esperado

```csharp
using System.IdentityModel.Tokens.Jwt;
using System.Security.Claims;
using System.Security.Cryptography;
using System.Text;
using Microsoft.AspNetCore.Identity;
using Microsoft.Extensions.Configuration;
using Microsoft.IdentityModel.Tokens;
using PortalEmpleo.Application.DTOs.Auth;
using PortalEmpleo.Application.Exceptions;
using PortalEmpleo.Application.Interfaces.Services;
using PortalEmpleo.Application.Interfaces.Repositories;
using PortalEmpleo.Domain.Entities;

namespace PortalEmpleo.Application.Services
{
    /// <summary>
    /// Service responsible for authentication operations.
    /// </summary>
    public class AuthService : IAuthService
    {
        private readonly IUserRepository _userRepository;
        private readonly IUnitOfWork _unitOfWork;
        private readonly IConfiguration _configuration;
        private readonly SignInManager<User> _signInManager;
        private readonly UserManager<User> _userManager;

        /// <summary>
        /// Initializes a new instance of AuthService.
        /// </summary>
        public AuthService(
            IUserRepository userRepository,
            IUnitOfWork unitOfWork,
            IConfiguration configuration,
            SignInManager<User> signInManager,
            UserManager<User> userManager)
        {
            _userRepository = userRepository;
            _unitOfWork = unitOfWork;
            _configuration = configuration;
            _signInManager = signInManager;
            _userManager = userManager;
        }

        /// <summary>
        /// Registers a new user in the system.
        /// </summary>
        /// <param name="registerDto">Registration data.</param>
        /// <returns>AuthResultDto containing JWT tokens and user info.</returns>
        /// <exception cref="InvalidCredentialsException">Thrown when email already exists.</exception>
        public async Task<AuthResultDto> RegisterAsync(RegisterDto registerDto)
        {
            var existingUser = await _userRepository.GetByEmailAsync(registerDto.Email);
            if (existingUser != null)
            {
                throw new InvalidCredentialsException("Email already registered");
            }

            var user = new User
            {
                Id = Guid.NewGuid(),
                Email = registerDto.Email,
                UserName = registerDto.Email,
                Name = registerDto.Name,
                BirthDate = registerDto.BirthDate,
                Phone = registerDto.Phone,
                Role = UserRole.CANDIDATE,
                IsActive = true,
                CreatedAt = DateTime.UtcNow,
                UpdatedAt = DateTime.UtcNow
            };

            var result = await _userManager.CreateAsync(user, registerDto.Password);
            if (!result.Succeeded)
            {
                var errors = string.Join(", ", result.Errors.Select(e => e.Description));
                throw new InvalidCredentialsException($"User creation failed: {errors}");
            }

            var (accessToken, accessTokenExpires, refreshToken, refreshTokenExpires) =
                await GenerateTokensAsync(user);

            await _userManager.AddToRoleAsync(user, UserRole.CANDIDATE.ToString());

            return new AuthResultDto
            {
                AccessToken = accessToken,
                RefreshToken = refreshToken,
                AccessTokenExpiresAt = accessTokenExpires,
                RefreshTokenExpiresAt = refreshTokenExpires,
                User = new UserDto
                {
                    Id = user.Id,
                    Email = user.Email,
                    Name = user.Name,
                    Role = user.Role
                }
            };
        }

        /// <summary>
        /// Authenticates a user and returns JWT tokens.
        /// </summary>
        /// <param name="loginDto">Login credentials.</param>
        /// <returns>AuthResultDto containing JWT tokens and user info.</returns>
        /// <exception cref="InvalidCredentialsException">Thrown when credentials are invalid.</exception>
        /// <exception cref="UserNotFoundException">Thrown when user is not found.</exception>
        /// <exception cref="UserInactiveException">Thrown when user account is inactive.</exception>
        public async Task<AuthResultDto> LoginAsync(LoginDto loginDto)
        {
            var user = await _userManager.FindByEmailAsync(loginDto.Email);
            if (user == null)
            {
                throw new UserNotFoundException("User not found");
            }

            if (!user.IsActive)
            {
                throw new UserInactiveException("User account is inactive");
            }

            var result = await _signInManager.CheckPasswordSignInAsync(
                user, loginDto.Password, false);

            if (!result.Succeeded)
            {
                throw new InvalidCredentialsException("Invalid credentials");
            }

            var (accessToken, accessTokenExpires, refreshToken, refreshTokenExpires) =
                await GenerateTokensAsync(user);

            var roles = await _userManager.GetRolesAsync(user);

            return new AuthResultDto
            {
                AccessToken = accessToken,
                RefreshToken = refreshToken,
                AccessTokenExpiresAt = accessTokenExpires,
                RefreshTokenExpiresAt = refreshTokenExpires,
                User = new UserDto
                {
                    Id = user.Id,
                    Email = user.Email,
                    Name = user.Name,
                    Role = user.Role
                }
            };
        }

        /// <summary>
        /// Refreshes access token using a valid refresh token.
        /// </summary>
        /// <param name="refreshTokenDto">Refresh token data.</param>
        /// <returns>AuthResultDto with new access token.</returns>
        /// <exception cref="InvalidRefreshTokenException">Thrown when refresh token is invalid.</exception>
        public async Task<AuthResultDto> RefreshTokenAsync(RefreshTokenDto refreshTokenDto)
        {
            var user = await _userRepository.GetByRefreshTokenAsync(refreshTokenDto.RefreshToken);
            if (user == null || user.RefreshTokenExpires < DateTime.UtcNow)
            {
                throw new InvalidRefreshTokenException("Invalid or expired refresh token");
            }

            var (accessToken, accessTokenExpires, refreshToken, refreshTokenExpires) =
                await GenerateTokensAsync(user);

            return new AuthResultDto
            {
                AccessToken = accessToken,
                RefreshToken = refreshToken,
                AccessTokenExpiresAt = accessTokenExpires,
                RefreshTokenExpiresAt = refreshTokenExpires,
                User = new UserDto
                {
                    Id = user.Id,
                    Email = user.Email,
                    Name = user.Name,
                    Role = user.Role
                }
            };
        }

        private async Task<(string accessToken, DateTime accessExpires, string refreshToken, DateTime refreshExpires)>
            GenerateTokensAsync(User user)
        {
            var jwtSettings = _configuration.GetSection("Jwt");
            var secretKey = jwtSettings["SecretKey"] ?? throw new InvalidOperationException("JWT secret not configured");
            var issuer = jwtSettings["Issuer"] ?? "PortalEmpleo";
            var audience = jwtSettings["Audience"] ?? "PortalEmpleoUsers";

            var accessTokenExpires = DateTime.UtcNow.AddMinutes(60);
            var refreshTokenExpires = DateTime.UtcNow.AddDays(7);

            var securityKey = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(secretKey));
            var credentials = new SigningCredentials(securityKey, SecurityAlgorithms.HmacSha256);

            var claims = new List<Claim>
            {
                new Claim(JwtRegisteredClaimNames.Sub, user.Id.ToString()),
                new Claim(JwtRegisteredClaimNames.Email, user.Email),
                new Claim(ClaimTypes.Role, user.Role.ToString()),
                new Claim(JwtRegisteredClaimNames.Jti, Guid.NewGuid().ToString()),
                new Claim(JwtRegisteredClaimNames.Exp, accessTokenExpires.ToString("yyyy-MM-dd HH:mm:ss"))
            };

            var token = new JwtSecurityToken(
                issuer: issuer,
                audience: audience,
                claims: claims,
                expires: accessTokenExpires,
                signingCredentials: credentials);

            var accessToken = new JwtSecurityTokenHandler().WriteToken(token);

            var refreshToken = Convert.ToBase64String(RandomNumberGenerator.GetBytes(32));
            user.RefreshToken = refreshToken;
            user.RefreshTokenExpires = refreshTokenExpires;
            await _userRepository.UpdateAsync(user);
            await _unitOfWork.SaveChangesAsync();

            return (accessToken, accessTokenExpires, refreshToken, refreshTokenExpires);
        }
    }
}
```

## Ejercicio 3: Controlador REST de Ofertas

### Prompt Efectivo

```markdown
Create a JobOffersController for a Job Portal API following REST best practices and ASP.NET Core conventions.

Base route: /api/v1/joboffers
Authentication: Bearer JWT token
Dependency injection: IJobOfferService

Endpoints to implement:

1. GET /api/v1/joboffers
   - Returns paginated list of PUBLISHED offers only
   - Query params: page (int, default 1), pageSize (int, default 10, max 100),
     q (string, search in title and description), location (string),
     contractType (ContractType enum), minSalary (decimal), maxSalary (decimal)
   - Order by CreatedAt descending
   - Response: 200 OK with PagedResult<JobOfferDto>

2. GET /api/v1/joboffers/{id:Guid}
   - Returns full offer details including company data
   - Response: 200 OK or 404 Not Found

3. POST /api/v1/joboffers
   - Creates new job offer in DRAFT status
   - Requires JWT authentication with COMPANY or ADMIN role
   - Request body: CreateJobOfferDto (all fields required)
   - Response: 201 Created with Location header
   - Response body: JobOfferDto

4. PUT /api/v1/joboffers/{id:Guid}
   - Updates existing offer
   - Only allows update if offer status is DRAFT or PAUSED
   - Requires JWT authentication, owner or ADMIN role
   - Request body: UpdateJobOfferDto
   - Response: 200 OK or 403 Forbidden or 404 Not Found

5. PATCH /api/v1/joboffers/{id:Guid}/status
   - Changes offer status
   - Request body: { status: JobOfferStatus }
   - Status transitions: DRAFT->PUBLISHED, PUBLISHED->PAUSED, PAUSED->PUBLISHED, any->CLOSED
   - Requires JWT authentication, owner or ADMIN role
   - Response: 200 OK or 400 Bad Request or 403 Forbidden

6. DELETE /api/v1/joboffers/{id:Guid}
   - Soft delete (sets IsActive = false)
   - Requires JWT authentication, owner or ADMIN role
   - Response: 204 No Content

Use [ApiController], [Route] attributes.
Use [Authorize] with role requirements: [Authorize(Roles = "COMPANY,ADMIN")]
Use IActionResult or ActionResult<T> return types.
Include [HttpGet], [HttpPost], [HttpPut], [HttpPatch], [HttpDelete] attributes.
Return only the C# code for the controller class.
```

### Código Generado Esperado

```csharp
using Microsoft.AspNetCore.Authorization;
using Microsoft.AspNetCore.Mvc;
using PortalEmpleo.Application.DTOs.JobOffer;
using PortalEmpleo.Application.Interfaces.Services;
using PortalEmpleo.Domain.Entities;
using System.Security.Claims;

namespace PortalEmpleo.API.Controllers
{
    /// <summary>
    /// API controller for job offer operations.
    /// </summary>
    [ApiController]
    [Route("api/v1/joboffers")]
    [Produces("application/json")]
    public class JobOffersController : ControllerBase
    {
        private readonly IJobOfferService _jobOfferService;

        /// <summary>
        /// Initializes a new instance of JobOffersController.
        /// </summary>
        public JobOffersController(IJobOfferService jobOfferService)
        {
            _jobOfferService = jobOfferService;
        }

        /// <summary>
        /// Gets a paginated list of published job offers.
        /// </summary>
        /// <param name="page">Page number (default: 1).</param>
        /// <param name="pageSize">Page size (default: 10, max: 100).</param>
        /// <param name="q">Search query for title and description.</param>
        /// <param name="location">Filter by location.</param>
        /// <param name="contractType">Filter by contract type.</param>
        /// <param name="minSalary">Minimum salary filter.</param>
        /// <param name="maxSalary">Maximum salary filter.</param>
        /// <returns>Paginated list of job offers.</returns>
        [HttpGet]
        [ProducesResponseType(typeof(PagedResult<JobOfferDto>), StatusCodes.Status200OK)]
        public async Task<ActionResult<PagedResult<JobOfferDto>>> GetJobOffers(
            [FromQuery] int page = 1,
            [FromQuery] int pageSize = 10,
            [FromQuery] string? q = null,
            [FromQuery] string? location = null,
            [FromQuery] ContractType? contractType = null,
            [FromQuery] decimal? minSalary = null,
            [FromQuery] decimal? maxSalary = null)
        {
            var query = new JobOfferQueryDto
            {
                Page = page,
                PageSize = Math.Min(pageSize, 100),
                Search = q,
                Location = location,
                ContractType = contractType,
                MinSalary = minSalary,
                MaxSalary = maxSalary
            };

            var result = await _jobOfferService.GetPublishedOffersAsync(query);
            return Ok(result);
        }

        /// <summary>
        /// Gets a job offer by its ID.
        /// </summary>
        /// <param name="id">Job offer ID.</param>
        /// <returns>Job offer details.</returns>
        [HttpGet("{id:Guid}")]
        [ProducesResponseType(typeof(JobOfferDto), StatusCodes.Status200OK)]
        [ProducesResponseType(StatusCodes.Status404NotFound)]
        public async Task<ActionResult<JobOfferDto>> GetJobOffer(Guid id)
        {
            var jobOffer = await _jobOfferService.GetByIdAsync(id);
            if (jobOffer == null)
            {
                return NotFound();
            }

            return Ok(jobOffer);
        }

        /// <summary>
        /// Creates a new job offer.
        /// </summary>
        /// <param name="createDto">Job offer creation data.</param>
        /// <returns>Created job offer.</returns>
        [HttpPost]
        [Authorize(Roles = "COMPANY,ADMIN")]
        [ProducesResponseType(typeof(JobOfferDto), StatusCodes.Status201Created)]
        [ProducesResponseType(StatusCodes.Status400BadRequest)]
        [ProducesResponseType(StatusCodes.Status401Unauthorized)]
        [ProducesResponseType(StatusCodes.Status403Forbidden)]
        public async Task<ActionResult<JobOfferDto>> CreateJobOffer([FromBody] CreateJobOfferDto createDto)
        {
            var userId = User.FindFirstValue(ClaimTypes.NameIdentifier);
            var jobOffer = await _jobOfferService.CreateAsync(createDto, Guid.Parse(userId!));

            return CreatedAtAction(
                nameof(GetJobOffer),
                new { id = jobOffer.Id },
                jobOffer);
        }

        /// <summary>
        /// Updates an existing job offer.
        /// </summary>
        /// <param name="id">Job offer ID.</param>
        /// <param name="updateDto">Job offer update data.</param>
        /// <returns>Updated job offer.</returns>
        [HttpPut("{id:Guid}")]
        [Authorize(Roles = "COMPANY,ADMIN")]
        [ProducesResponseType(typeof(JobOfferDto), StatusCodes.Status200OK)]
        [ProducesResponseType(StatusCodes.Status400BadRequest)]
        [ProducesResponseType(StatusCodes.Status401Unauthorized)]
        [ProducesResponseType(StatusCodes.Status403Forbidden)]
        [ProducesResponseType(StatusCodes.Status404NotFound)]
        public async Task<ActionResult<JobOfferDto>> UpdateJobOffer(
            Guid id,
            [FromBody] UpdateJobOfferDto updateDto)
        {
            var userId = User.FindFirstValue(ClaimTypes.NameIdentifier);
            var jobOffer = await _jobOfferService.UpdateAsync(id, updateDto, Guid.Parse(userId!));

            return Ok(jobOffer);
        }

        /// <summary>
        /// Updates the status of a job offer.
        /// </summary>
        /// <param name="id">Job offer ID.</param>
        /// <param name="statusDto">New status data.</param>
        /// <returns>Updated job offer.</returns>
        [HttpPatch("{id:Guid}/status")]
        [Authorize(Roles = "COMPANY,ADMIN")]
        [ProducesResponseType(typeof(JobOfferDto), StatusCodes.Status200OK)]
        [ProducesResponseType(StatusCodes.Status400BadRequest)]
        [ProducesResponseType(StatusCodes.Status401Unauthorized)]
        [ProducesResponseType(StatusCodes.Status403Forbidden)]
        public async Task<ActionResult<JobOfferDto>> UpdateJobOfferStatus(
            Guid id,
            [FromBody] UpdateJobOfferStatusDto statusDto)
        {
            var userId = User.FindFirstValue(ClaimTypes.NameIdentifier);
            var jobOffer = await _jobOfferService.UpdateStatusAsync(
                id,
                statusDto.Status,
                Guid.Parse(userId!));

            return Ok(jobOffer);
        }

        /// <summary>
        /// Soft deletes a job offer.
        /// </summary>
        /// <param name="id">Job offer ID.</param>
        /// <returns>No content.</returns>
        [HttpDelete("{id:Guid}")]
        [Authorize(Roles = "COMPANY,ADMIN")]
        [ProducesResponseType(StatusCodes.Status204NoContent)]
        [ProducesResponseType(StatusCodes.Status401Unauthorized)]
        [ProducesResponseType(StatusCodes.Status403Forbidden)]
        [ProducesResponseType(StatusCodes.Status404NotFound)]
        public async Task<IActionResult> DeleteJobOffer(Guid id)
        {
            var userId = User.FindFirstValue(ClaimTypes.NameIdentifier);
            await _jobOfferService.DeleteAsync(id, Guid.Parse(userId!));

            return NoContent();
        }
```

```csharp
using FluentValidation;
using Microsoft.Extensions.DependencyInjection;
using PortalEmpleo.Application.DTOs.Auth;
using PortalEmpleo.Application.Interfaces.Repositories;

namespace PortalEmpleo.Application.Validators
{
    /// <summary>
    /// Validator for user registration DTO.
    /// </summary>
    public class RegisterDtoValidator : AbstractValidator<RegisterDto>
    {
        private readonly IServiceProvider _serviceProvider;

        /// <summary>
        /// Initializes a new instance of RegisterDtoValidator.
        /// </summary>
        public RegisterDtoValidator(IServiceProvider serviceProvider)
        {
            _serviceProvider = serviceProvider;

            RuleFor(x => x.Email)
                .NotEmpty()
                .WithMessage("El correo electrónico es obligatorio")
                .MaximumLength(256)
                .WithMessage("El correo electrónico no puede exceder los 256 caracteres")
                .EmailAddress()
                .WithMessage("El formato del correo electrónico no es válido")
                .MustAsync(async (email, cancellation) =>
                {
                    using var scope = _serviceProvider.CreateScope();
                    var userRepository = scope.ServiceProvider.GetRequiredService<IUserRepository>();
                    return await userRepository.ExistsByEmailAsync(email) == false;
                })
                .WithMessage("El correo electrónico ya está registrado");

            RuleFor(x => x.Password)
                .NotEmpty()
                .WithMessage("La contraseña es obligatoria")
                .MinimumLength(8)
                .WithMessage("La contraseña debe tener al menos 8 caracteres")
                .Matches("[A-Z]")
                .WithMessage("La contraseña debe contener al menos una letra mayúscula")
                .Matches("[a-z]")
                .WithMessage("La contraseña debe contener al menos una letra minúscula")
                .Matches("[0-9]")
                .WithMessage("La contraseña debe contener al menos un número")
                .Matches(@"[@$!%*?&]")
                .WithMessage("La contraseña debe contener al menos un carácter especial");

            RuleFor(x => x.Name)
                .NotEmpty()
                .WithMessage("El nombre es obligatorio")
                .MaximumLength(100)
                .WithMessage("El nombre no puede exceder los 100 caracteres")
                .Must(name => !string.IsNullOrWhiteSpace(name))
                .WithMessage("El nombre no puede estar vacío");

            RuleFor(x => x.BirthDate)
                .NotEmpty()
                .WithMessage("La fecha de nacimiento es obligatoria")
                .Must(birthDate => birthDate <= DateTime.UtcNow.AddYears(-16))
                .WithMessage("Debes tener al menos 16 años para registrarte");

            RuleFor(x => x.Phone)
                .MaximumLength(20)
                .WithMessage("El teléfono no puede exceder los 20 caracteres")
                .Matches(@"^\+?[1-9]\d{1,14}$")
                .When(x => !string.IsNullOrWhiteSpace(x.Phone))
                .WithMessage("El formato del teléfono no es válido");
        }
    }
}
```
