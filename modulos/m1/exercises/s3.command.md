/create-prompt 

Crea un prompt en este proyecto para generar los modelos de un módulo del proyecto
- Input: El prompt debe poder recibir como input la referencia a la sección de especificación del módulo en el documento `docs\01.caso-practico.md`.
- Deberá leer la sección correspondiente a ese módulo, identificar las entidades y sus atributos, y generar el código de los modelos siguiendo las convenciones definidas en el proyecto.
