Crea un Agent Skill para el proyecto PortalEmpleo API con las siguientes especificaciones:

## Metadata del Skill

- **name:** test-quality-security
- **description:** Genera, ejecuta y valida tests de seguridad y calidad para PortalEmpleo API (xUnit + Moq + FluentAssertions). Usar cuando se necesite verificar la correctitud, seguridad y calidad de un componente recién implementado: validación de entrada, autenticación, autorización, integridad de datos y cobertura de criterios de aceptación.
- **argument-hint:** [component-name, feature-name] — ejemplo: [AuthService, user-auth]

## Instrucciones del Skill

El SKILL.md debe incluir:

### Inputs requeridos
- `component-name`: Nombre del componente a testear (ejemplo: `AuthService`)
- `feature-name`: Nombre de la feature asociada (ejemplo: `user-auth`)

### Proceso de generación de tests

1. **Analizar specs de la feature**
   - Leer `specs\<feature-name>\spec.md` (ejemplo: `specs\001-user-auth\spec.md`)
   - Extraer criterios de aceptación funcionales y no funcionales

2. **Analizar RF + RNF del caso práctico**
   - Leer `docs\01.caso-practico.md`
   - Identificar requisitos funcionales y no funcionales asociados al `component-name`

3. **Generar tests de calidad y seguridad**
   - Crear tests pertinentes según el componente: autenticación, autorización, validación de entrada, integridad de datos, manejo de errores, boundary conditions
   - Stack obligatorio: **xUnit + Moq + FluentAssertions**
   - Nombrar los tests con el patrón: `[Método]_[Escenario]_[ResultadoEsperado]`
   - Ubicar los tests en la carpeta de tests del proyecto correspondiente

4. **Ejecutar los tests generados**
   - Ejecutar **únicamente** los tests recién creados
   - Capturar la salida completa: resultados, errores de compilación y errores de ejecución

5. **Entregar resultado al agente invocador**
   - Reportar: número de tests generados, tests pasados/fallidos, errores encontrados
   - NO corregir errores de implementación del componente — solo reportarlos

### Límites del skill (scope boundaries)
- ✅ Genera tests de calidad y seguridad
- ✅ Ejecuta los tests generados
- ✅ Reporta resultados al agente invocador
- 🚫 No corrige errores en el código del componente testeado
- 🚫 No modifica la implementación del componente

### Rol en el flujo de desarrollo
Este skill actúa como **subagente especializado en testing** dentro del flujo de implementación. Debe invocarse **después** de que el agente principal haya generado el código del componente a testear.
