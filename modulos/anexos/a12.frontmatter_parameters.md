## Detalle por Tipo

### Prompt Files (.prompt.md)

Extensión: `.prompt.md`
Ubicación: `.github/prompts/` (workspace) o perfil de usuario

| Parámetro | Tipo | Descripción |
|-----------|------|-------------|
| `description` | string | Descripción corta del prompt |
| `name` | string | Nombre para el slash command `/` |
| `argument-hint` | string | Hint para el usuario en el campo de chat |
| `agent` | string | Agente a usar: `ask`, `agent`, `plan`, o nombre de custom agent |
| `model` | string | Modelo de lenguaje a utilizar |
| `tools` | array | Lista de herramientas disponibles |

### Custom Agents (.agent.md)

Extensión: `.agent.md`
Ubicaciones: `.github/agents/`, `.claude/agents/`, `~/.copilot/agents/`

| Parámetro | Tipo | Descripción |
|-----------|------|-------------|
| `name` | string | Nombre del agente |
| `description` | string | Descripción (placeholder en chat) |
| `argument-hint` | string | Hint para interacción en chat |
| `tools` | array | Herramientas o sets de herramientas disponibles |
| `agents` | array | Subagentes permitidos (`*` para todos, `[]` para ninguno) |
| `model` | string/array | Modelo(s) a usar (prioridad si es array) |
| `user-invocable` | boolean | Visible en dropdown de agentes (default: true) |
| `disable-model-invocation` | boolean | Previene invocación como subagente (default: false) |
| `infer` | boolean | Deprecated - usar las dos propiedades anteriores |
| `target` | string | Entorno: `vscode` o `github-copilot` |
| `mcp-servers` | object | Configuración de servidores MCP (solo github-copilot) |
| `handoffs` | array | Transiciones guiadas a otros agentes |
| `hooks` | array | Comandos hook scoped al agente (Preview) |

#### Handoffs Structure

```yaml
handoffs:
  - label: string          # Texto del botón
    agent: string         # Agente destino
    prompt: string        # Prompt a enviar
    send: boolean         # Auto-submit (default: false)
    model: string         # Modelo opcional para el handoff
```

### Agent Skills (SKILL.md)

Archivo: `SKILL.md` dentro de carpeta del skill
Ubicaciones: `.github/skills/`, `.claude/skills/`, `~/.copilot/skills/`
Estándar: [agentskills.io](https://agentskills.io/) - portabilidad cross-agent

| Parámetro | Tipo | Descripción |
|-----------|------|-------------|
| `name` | string | **Requerido**. ID único (lowercase, números, guiones; max 64 chars) |
| `description` | string | **Requerido**. Qué hace y cuándo usarlo (max 1024 chars) |
| `argument-hint` | string | Hint para slash command |
| `user-invocable` | boolean | Visible como `/comando` (default: true) |
| `disable-model-invocation` | boolean | Solo carga manual, no automática (default: false) |
| `context` | string | Experimental: `inline` (default) o `fork` |

#### Context: Fork (Experimental)

```yaml
context: fork  # Ejecuta en subagent dedicado, solo retorna resultado final
```

## Parámetros Exclusivos

| Tipo | Parámetros únicos |
|------|-------------------|
| Prompt Files | `agent` |
| Custom Agents | `handoffs`, `hooks`, `agents` |
| Agent Skills | `context` |
